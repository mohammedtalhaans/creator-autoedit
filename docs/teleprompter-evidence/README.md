# Teleprompter evidence

These files are dated local evidence from the controlled Chromium runs:

- [record-composite-desktop.png](record-composite-desktop.png) and
  [record-composite-mobile.png](record-composite-mobile.png) show the reader
  over the live viewfinder.
- [script-mobile.png](script-mobile.png) shows the first-use mobile script
  layout; [takes-library.png](takes-library.png) shows the saved take library.
- [composite-finalcheck.png](composite-finalcheck.png) is the settled overlay
  check frame.
- [teleprompter-native-take.mp4](teleprompter-native-take.mp4) is the original
  downloaded native take from the fake camera/microphone run (249,491 bytes).
- [model-voice.json](model-voice.json) and [model-writing.json](model-writing.json)
  contain actual local model probe results and immutable revisions.

Fake media is used only to make browser capture reproducible. It does not
represent a physical camera, microphone, mobile device, thermal profile, or
Safari codec result.
